# Клип Баттл

## Деплой на Render.com
1. Залейте эту папку в новый репозиторий на GitHub.
2. На render.com: New + → Web Service → выберите репозиторий.
3. Настройки:
   - Runtime: Node
   - Build Command: npm install
   - Start Command: npm start
   - Plan: Free
4. Deploy — через пару минут получите ссылку вида https://ваш-проект.onrender.com
